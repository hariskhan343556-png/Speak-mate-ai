# SpeakMate Streamlit deployment

Repository root must contain `app.py` and the following directories:
`components/`, `database/`, `pages/`, `services/`, `utils/`.

Streamlit Cloud:
- Branch: `main`
- Main file path: `app.py`

Add required API keys and other secrets through Streamlit Cloud Secrets.
Do not commit real `.env` files or API keys.
